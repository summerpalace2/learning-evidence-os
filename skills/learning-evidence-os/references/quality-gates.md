# Quality Gates

The following gates convert the protocol from a set of ideas into a reviewable operating contract. A domain Profile may add checks but must not remove the core evidence boundaries.

## A. Double Loop Gate

- [ ] Scope is explicit.
- [ ] Coverage Discovery created an independent candidate map before trusting the existing map.
- [ ] New increments received a placement decision.
- [ ] Coverage C is not confused with learner L or answer R.
- [ ] Learning Verification restored state and used live evidence.
- [ ] Follow-up depth reflected the learner answer.
- [ ] The scoped map and question coverage were re-checked.

## B. Assessment and question-bank gate

- [ ] Original question, follow-up, hint, normalized question, and AI extension are distinguishable.
- [ ] Source evidence strength is recorded when relevant.
- [ ] The pipeline Input → Parse → Evaluate → Standardize → Persist → Next Loop completed.
- [ ] Important questions have concise, complete, and deeper canonical answers.
- [ ] Shared question quality is separate from personal performance.

## C. Article production gate

- [ ] Scope, sources, and exclusions are frozen.
- [ ] Knowledge boundary and dependencies are explicit.
- [ ] Technical truth and version conflicts are checked.
- [ ] The causal chain, engineering mapping, boundaries, and mistakes are complete.
- [ ] Learner annotations are evidence-backed and local to the relevant content.
- [ ] Code blocks declare the correct language and remain readable.
- [ ] Diagrams are present where useful, visually checked, and do not replace essential prose.
- [ ] Article links support both article → node and node → exact article section.

## D. Canonical answer gate

- [ ] The answer asset exists before learner evaluation closes.
- [ ] Original and normalized questions are recorded.
- [ ] Short, complete, and deeper answers are available where warranted.
- [ ] Boundaries, follow-ups, sources, and validation state are present.
- [ ] Canonical answer and learner raw answer are not mixed.

## E. Acceptance board gate

- [ ] A formal Topic uses one cumulative board with numbered rounds.
- [ ] Every round records scope, questions, raw-answer summaries, prompts, R, corrections, links, and retest items.
- [ ] One answer does not automatically raise a Topic L.
- [ ] Topic closure preserves unresolved work and creates a next handoff.

## F. Navigation gate

- [ ] Every article-backed node has a root, precise locator, and version.
- [ ] Deep links open the intended section.
- [ ] Article sections link back to the relevant node, answer, and evidence.
- [ ] A content change repairs affected navigation in the same writeback.

## G. Writeback gate

- [ ] Facts freeze first.
- [ ] Canonical answer, Session, Evidence, nodes, article, Topic State, and control view update in order.
- [ ] Shared question banks contain only reusable de-personalized assets.
- [ ] Incomplete work is not written as completed.
- [ ] Final Sync re-reads the current state and leaves one executable next action.
