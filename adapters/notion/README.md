# Notion Adapter

Notion 适合作为个人学习控制中心，而不是全部知识正文的容器。

## 推荐对象

- Topic 与 Checkpoint；
- Topic State；
- Learning Session；
- Evaluation Evidence；
- Acceptance Board；
- Current Learning Board；
- handoff 与文章深链。

## 必须能力

- 用稳定 Page 或 Database ID 建立关系；
- 从节点跳到文章精确小节，并保留文章版本；
- 把用户原话和 AI 标准答案保存在不同属性或页面中；
- 写回失败时返回对象级失败，不更新“完成”状态；
- 不把 OAuth Token、私有页面 URL 或完整导出放入公共仓库。
